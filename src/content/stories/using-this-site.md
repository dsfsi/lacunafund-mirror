## Data for equitable machine learning

Lacuna Fund supports data scientists, researchers, and social entrepreneurs working with communities in low- and middle-income contexts globally. This space shares updates about the people, partnerships, and datasets that make that work possible.

## Add a story without changing the site code

Create a new file in `src/content/stories/` with a descriptive filename such as `new-grantmaking-update.md`. Copy the short information block at the top of this story, then write the article below it in ordinary Markdown.

- Use `##` for section headings.
- Use blank lines between paragraphs.
- Use `[link text](https://example.org)` for links.
- Use `-` for bullet points.

The site automatically creates the story page and adds it to the Stories listing at build time.
